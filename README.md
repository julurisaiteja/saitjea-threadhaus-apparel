# Threadhaus (sai-threadhaus-apparel)

Diamond storefront — High fashion Editorial — runway whitespace, oversized type.

## Run locally

```bash
npm i
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

- `npm run dev` — development server
- `npm run build` — production build
- `npm start` — serve production build

## Features

- Style-map unique homepage (fashion-hero)
- Niche film hero + soft CSS motion
- Catalog, deep PDP, offers, reviews, AI assistant
- Cart → checkout → success (demo payments)
- Special experience at `/special`

Demo only — no real payments.
